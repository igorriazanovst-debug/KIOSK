**Документ требуется ТЗ:** перечень сторонних компонентов и их лицензий; раздел 10 — «разработчик должен обеспечить законность использования всех поставляемых изображений, аудио, видео, текстов, шрифтов и иных материалов».

**Дата сверки:** 13.09.2026. Версии взяты из фактически установленных пакетов (`node_modules/*/package.json`), а не из диапазонов в `package.json` — на приёмку едет то, что собрано, а не то, что разрешено собрать.

## 2. Материалы контента — ГЛАВНЫЙ ОТКРЫТЫЙ ВОПРОС

Этот раздел не закрыт, и закрыть его разработчик не может.

### 2.1. Иллюстрации — созданы генеративной моделью

**Что сделано:** 95 иллюстраций слов созданы моделью Nano Banana через сервис SYNTX.AI (13.09.2026) по текстовым описаниям, написанным в этом проекте. Описания — в `packages/alphabet-library/tools/illustration-prompts.mjs`.

**Что не закрыто:** правовой статус изображений, созданных генеративной моделью, — вопрос к юристу заказчика. Требуется решение по трём пунктам:

1. Признаётся ли такое изображение пригодным для поставки в коммерческом продукте;
2. Каковы обязательства перед сервисом-генератором по его условиям использования;
3. Нужна ли атрибуция и в какой форме.

**До решения** иллюстрации считаются временными. Заменяются один в один: файлы лежат по именам, выведенным из идентификатора слова, и подмена ничего больше не затрагивает.

### 2.2. Озвучка — синтезирована

**Что сделано:** 372 файла синтезированы Windows SAPI (голос Microsoft Irina Desktop), сведены в mp3 средствами ffmpeg.

**Что не закрыто:**

1. **Правовая сторона.** Голоса Microsoft SAPI поставляются с Windows; их использование для синтеза речи в распространяемом продукте регулируется лицензией Windows и условиями использования голосового пакета. Требуется проверка юристом.
2. **Методическая сторона.** ТЗ требует «озвученные слова», не уточняя способ. Пригоден ли синтезированный голос для пособия **по развитию речи** — решает заказчик или методист.

**До решения** озвучка — средство разработки: она сделала игру проверяемой на слух. Схема, раскладка и имена файлов при замене на живой голос не меняются.

### 2.3. Словарь — написан в этом проекте

95 слов, их разбивка на слоги и состав комплектов написаны здесь (`packages/alphabet-library/tools/catalogue.mjs`), а не взяты у эталона ОС3. Сами слова — обиходные русские существительные; совпадения с чужим списком неизбежны и правового значения не имеют.

**Ресурсы продукта ОС3 «АзбукоСлов» не использовались ни в каком виде** — ни изображения, ни звук, ни файлы данных. Из разбора эталона заимствованы только сведения об **устройстве** продукта (раскладка файлов, число вариантов на панели, структура статистики), которые фактами, а не произведениями, и являются.

### 2.4. Шрифты

Собственных шрифтов виджет не поставляет. Интерфейс использует системные (`system-ui`, `Georgia`, `Times New Roman`) — они входят в состав операционной системы и с продуктом не распространяются.

## 3. Что требуется от заказчика

| Вопрос | Кто решает |
|---|---|
| Пригодность изображений, созданных нейросетью, для поставки | юрист заказчика |
| Обязательства перед сервисом-генератором | юрист заказчика |
| Пригодность синтезированной речи для пособия по развитию речи | методист |
| Правовой статус голосов Microsoft SAPI в распространяемом продукте | юрист заказчика |

**Реестр источников и лицензий на каждый материал контента не заведён** — его имеет смысл начинать после решения по пунктам выше, когда станет понятно, какие материалы остаются в поставке.
