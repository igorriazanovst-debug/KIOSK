# Инструкция администратора: виджет «Я знаю много слов» (Тип 2)

**Документ требуется ТЗ:** раздел 11 («подготовить установочный пакет и инструкцию по установке/удалению»), раздел 13 (позиции «инструкция администратора/установки», «описание форматов пользовательских данных и резервного копирования»).

**Для кого:** тот, кто готовит проект в редакторе KIOSK, собирает дистрибутив и ставит его на устройство. Инструкция для педагога и детей — отдельный документ (по состоянию на 11.09.2026 не написан: он требует скриншотов с настоящим контентом).

**Состояние продукта на 11.09.2026:** виджет работает на **заглушках контента** — 4 темы, 20 слов, озвучки нет. Ставить на реальное занятие рано; инструкция описывает готовый механизм, чтобы его можно было проверить и чтобы не переписывать её потом.

---

## 1. Что это

Новый тип виджета в редакторе KIOSK. В отличие от прямоугольных виджетов на холсте, он занимает **весь экран**: проект, в котором стоит виджет «Я знаю много слов», собирается в **оконном режиме** вместо киоск-полноэкранного. Так же устроены «Хронолиния», «Конструктор природных сообществ» и «Матемашка».

Из этого следуют два практических вывода:

- заданные в редакторе размер и положение виджета игнорируются — задавать их аккуратно смысла нет;
- **не ставьте на один проект этот виджет и обычные виджеты холста** — обычные видны не будут.

## 2. Как выдать доступ

Виджет виден в библиотеке редактора не всем: список разрешённых адресов задан константой `WORDS_ALLOWED_EMAILS` в `packages/editor-web/src/components/WidgetLibrary.tsx`.

Чтобы добавить пользователя: внести адрес в этот список, пересобрать `editor-web` и выложить сборку (раздел 5). Список маленький и временный — отдельной таблицы в базе под него намеренно нет.

> Это скрытие в интерфейсе, а не запрет на сервере. Пока виджет на обкатке, этого достаточно; при выходе на прод нужен второй рубеж — серверная проверка, как у «Хронолинии» (`chronolineAccess.ts`).

## 3. Как собрать проект с виджетом

1. Открыть редактор, создать проект.
2. Перетащить на холст виджет **«Я знаю много слов»**.
3. В панели свойств задать: уровень сложности по умолчанию, число игроков за столом (2–4), громкость, длину партии.
4. Собрать дистрибутив штатным механизмом KIOSK (кнопка сборки → `/api/builds`), скачать `.exe`, установить на устройство.

Настройки из панели свойств — значения **по умолчанию** для устройства. Педагог может изменить их на месте, в разделе «Настройки» самого приложения.

## 4. Разделы педагога и защита от детей

Пунктов «Мои слова» и «Настройки» в меню приложения нельзя коснуться случайно: кнопку нужно **удерживать две секунды**, после чего появится подтверждение. Удаление игрока — тоже удержанием.

Пароля нет намеренно: профили детей — не учётные записи операционной системы, и ТЗ требует защиты от **случайного** изменения, а не аутентификации. Педагогу у доски не нужно ничего вводить.

**Что это значит для вас:** если педагог жалуется, что «кнопка не нажимается» — она нажимается удержанием, и под ней написано об этом. Полоса заливки показывает прогресс.

## 5. Обновление после правок кода

Порядок сборки пакетов монорепо — по зависимостям, иначе соберётся старое:

```
1) packages/shared      npm install && npm run build
2) packages/chrono-ui   npm install && npm run build     # нужен плееру
3) packages/player      npm install                      # сборка идёт по запросу
4) packages/editor-web  npm install && npm run build
```

**После КАЖДОГО `npm install` проверяйте симлинки:**

```
ls -la packages/player/node_modules/@kiosk/
ls -la packages/editor-web/node_modules/@kiosk/
```

В проекте нет npm workspaces — связи между пакетами держатся на ручных симлинках, и `npm install` считает их лишними и сносит. Если симлинк пропал, восстановите его **до** рестарта сервиса и до первой сборки клиента.

Отдельно про `packages/player`: рестарт не нужен (это не сервис, а исходники для сборки по запросу), но `npm install` при новых зависимостях **обязателен вручную** — автоматический запускается только когда `node_modules` отсутствует целиком, а не когда он устарел. Иначе первая же клиентская сборка тихо возьмёт старые зависимости.

`editor-web` раздаётся статикой из `/opt/kiosk/editor-web`, а не из `packages/editor-web/dist`: соберите, сделайте резервную копию раздаваемой папки с меткой времени в имени, скопируйте новую сборку поверх.

## 6. Где лежат данные на устройстве

```
C:\ProgramData\kiosk-words\
├── profiles.json     профили детей
├── settings.json     громкость, режим устройства, уровни по темам
├── scores.json       достижения: профиль → тема → ступень
├── my_words.json     свои слова педагога
├── my_sets.json      свои комплекты
└── media\            картинки и записи педагога, имена — хеш содержимого
```

Каталог **общий на машину**, а не на пользователя Windows: в классе за одним компьютером работают под разными учётками, и работа детей должна быть видна независимо от того, кто вошёл в систему. Если прав на запись туда нет, приложение переходит на пользовательский каталог и сообщает об этом в логе — это аварийный режим, а не рабочий.

Все файлы — обычный JSON с полем `schemaVersion`. Запись атомарная: сначала временный файл, потом переименование, поэтому выключение питания посреди сохранения не оставляет обрывок под рабочим именем.

**Повреждённый файл — это явная ошибка с сообщением, а не «список пуст».** Так сделано намеренно: молча обнулившийся список профилей педагог прочитает как потерю работы детей.

## 7. Резервное копирование и перенос

**Копировать целиком** `C:\ProgramData\kiosk-words\`. Файлы самодостаточны, база данных не используется, служб останавливать не нужно — но копируйте при закрытом приложении, иначе можно поймать момент между записью JSON и записью медиа.

**Восстановление:** положить каталог обратно на место при закрытом приложении.

**Перенести только комплект слов** (без профилей и статистики) можно средствами самого приложения: «Мои слова» → у комплекта кнопка **«Экспорт»** → файл `.kwset`. На другом устройстве — **«Импорт»**.

Что происходит при импорте:

- свои слова педагога едут целиком, вместе с картинкой и записью;
- поставочные слова **не едут** — в файле только их идентификаторы, а само слово берётся из библиотеки принимающего устройства;
- если на принимающем устройстве поставочного слова нет (другая версия пакета контента), оно выпадает из комплекта, а импорт продолжается — приложение перечислит выпавшие слова на экране;
- слово, которое на этом устройстве уже есть, повторно не заводится;
- комплект с занятым названием получит суффикс: «Урок (2)».

Файл `.kwset` — это ZIP с фиксированной структурой. Импортируются только файлы ожидаемого вида, и каждая картинка и запись проверяется **по содержимому**, а не по расширению: подменённый файл будет отвергнут.

## 8. Удаление

1. Удалить приложение штатным средством Windows («Параметры» → «Приложения»).
2. Данные при этом **остаются** — это сделано намеренно, чтобы переустановка не уносила работу детей. Если данные тоже не нужны, удалить каталог `C:\ProgramData\kiosk-words\` вручную.

## 9. Если что-то пошло не так

| Симптом | Где смотреть |
|---|---|
| Карта тем пустая | Лог приложения: строка `[words] WARNING: content library ... not found`. Пакет контента не попал в сборку |
| Слово без озвучки, показывается текстом с пометкой | Так и задумано, пока озвучка не записана. Это признак незаконченного пакета контента, а не режим продукта |
| «Не удалось сохранить»/«Нет доступа» | Права на запись в `C:\ProgramData\kiosk-words`. В логе будет `(fallback: no write access to shared dir)` |
| Приложение открылось в окне, а не на весь экран | Так и задумано: проект с этим виджетом собирается в оконном режиме |
| Микрофон не даёт записать | Проверить разрешение на микрофон в параметрах конфиденциальности Windows. Само приложение разрешений не запрашивает отдельно — оно опирается на системные |

## 10. Чего в продукте пока нет

Чтобы не искать несуществующее:

- **автообновления** — механизм не реализован ни в виджете, ни в плеере KIOSK (ТЗ FR-023, открытый вопрос);
- **поставочного контента** — 4 темы вместо 15, 20 слов вместо 250, озвучки нет;
- **версии для Android** — планируется отдельным нативным приложением;
- **поддержки Windows 7 и 8** — плеер собран на Electron 39, эти системы им не поддерживаются.
