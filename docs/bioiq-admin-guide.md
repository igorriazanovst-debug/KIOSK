## 1. Что устанавливается

«БиоIQ» — не отдельная программа, а виджет плеера KIOSK. На компьютер ставится плеер, а виджет открывается тем проектом, который в плеер положен.

Когда в проекте один виджет `bioiq` на весь канвас, плеер открывается **полноэкранным окном приложения** — без рамки, без панели инструментов редактора. Так собираются учебные места.

Контент викторины (три карты уровней и шесть тематических изображений) **входит в сборку плеера**. Отдельно ничего докладывать не нужно.

## 2. Где лежат данные

```
%APPDATA%\kiosk-bioiq
```

обычно `C:\Users\<имя>\AppData\Roaming\kiosk-bioiq`.

| Что | Где |
|---|---|
| История партий, статистика, PIN, настройки | `userdata.json` |
| Викторины учителя вместе с изображениями | папка `quizzes` |

**Это профиль пользователя, а не общий каталог, — и это важно для администратора.** Виджеты «Я знаю много слов», «АзбукоСлов» и «Инофон» хранят данные в `%ProgramData%`, общем для всех учётных записей машины. «БиоIQ», как «РусIQ» и «ХимIQ», хранит их в профиле.

Следствия:

- если учителя работают за одним компьютером под **разными учётными записями Windows**, викторины одного не будут видны другому;
- перенос профиля Windows переносит и викторины;
- резервная копия машины должна включать `%APPDATA%`, иначе работа учителя не сохранится.

Если прав на запись нет, виджет пишет во временный каталог и **сообщает об этом на экране** — молча он не переключается.

## 3. Перенос викторин между компьютерами

Штатный способ — **экспорт в файл**: в каталоге режима учителя у каждой викторины есть «Экспорт в файл», результат — один самодостаточный `.bioiq.json` с вопросами и изображениями внутри. На другой машине — «Импортировать викторину».

Копировать папку `quizzes` целиком тоже можно, но тогда переносите её **полностью**: изображения лежат рядом с описанием викторины, и частичный перенос даст викторину без карт уровней.

> Расширение `.bioiq.json` не совпадает с `.chimiq.json` намеренно. Викторины по биологии и по химии не взаимозаменяемы, и открытие одной вместо другой выглядело бы как порча данных.

## 4. Доступ к виджету в редакторе

Виджет виден в библиотеке редактора не всем: список разрешённых адресов задан в двух местах, и **оба обязательны**.

| Где | Файл | Что делает |
|---|---|---|
| Клиент | `packages/editor-web/src/components/WidgetLibrary.tsx`, `BIOIQ_ALLOWED_EMAILS` | скрывает виджет из библиотеки |
| Сервер | `packages/server/src/config/bioiqAccess.ts`, `BIOIQ_ALLOWED_EMAILS` | отклоняет сохранение проекта с этим виджетом |

Клиентское скрытие без серверной проверки — не ограничение, а видимость ограничения: проект с виджетом можно было бы сохранить в обход интерфейса. Этот класс дыры уже находили и закрывали у Типов 2 и 3.

## 5. Сброс PIN режима учителя

Программа PIN не показывает и не восстанавливает — это пароль.

Сброс: удалить `userdata.json` из каталога данных. При следующем запуске PIN спросят заново.

> **Вместе с файлом пропадёт вся статистика.** Викторины в папке `quizzes` при этом уцелеют — они лежат отдельно. Если статистика нужна, сначала скопируйте файл в сторону.

## 6. Разбор неполадок

**Виджета нет в библиотеке редактора.** Адрес учётной записи не в списке разрешённых — см. раздел 4. Проверьте оба места.

**Плеер открывается окном редактора, а не полноэкранным приложением.** В проекте больше одного виджета либо виджет не на весь канвас. Полноэкранный режим включается, когда `bioiq` — единственный виджет проекта.

**«Не удалось прочитать сохранённые данные».** Файл `userdata.json` повреждён. Программа начинает с чистого состояния и **говорит об этом**, а не выдаёт пустую историю за настоящую. Восстановить историю можно только из резервной копии.

**Учитель не видит своих викторин.** Проверьте учётную запись Windows (раздел 2).

**В своей викторине правильный ответ не засчитывается.** Области ответов налезли друг на друга: сверху оказалась чужая, и клик достаётся ей. Откройте викторину в редакторе — панель «Готовность викторины» назовёт налезающие области по именам.

**Изображение уровня не открывается.** Папку `quizzes` перенесли частично — изображение осталось на старом месте. См. раздел 3.

## 7. Пересборка контента

Весь контент викторины собирается скриптами из репозитория, и это воспроизводимо:

```sh
cd packages/player

# 1. Тематические изображения (6 шт.)
node tools/bioiq/draw-thematic.mjs
electron.exe tools/bioiq/render-thematic.cjs tools/bioiq/svg public/bioiq/thematic

# 2. Карты уровней (3 шт.) + координаты структур
node tools/bioiq/draw-levels.mjs tools/bioiq/levelsvg
electron.exe tools/bioiq/render-thematic.cjs tools/bioiq/levelsvg public/bioiq

# 3. Викторина из карт и банка вопросов
node tools/bioiq/build-content.mjs
```

Шаг 2 **падает**, если области на карте налезают друг на друга или выходят за край изображения. Это не придирка: на игровом поле все области кликабельны одновременно, и наложенные дают кнопку поверх кнопки.

Шаг 3 **падает**, если вопрос ссылается на структуру, которой на карте нет. Координаты никогда не переписываются руками: рисунок — единственный их источник.

Отладочная версия карт с наложенными областями и именами (посмотреть глазами, лежит ли область на своём объекте):

```sh
node tools/bioiq/overlay-structures.mjs
electron.exe tools/bioiq/render-thematic.cjs tools/bioiq/overlay <куда>
```

Она нужна потому, что автоматическая проверка знает про наложение областей, но не знает, что нарисовано под областью: прямоугольник с именем «митохондрия», лежащий на пустой цитоплазме, для неё безупречен.

Снимки для инструкции пользователя:

```sh
cd docs/tools
./restand.sh stage-bioiq 9680 kiosk-bioiq kiosk-bioiq
node shoot.mjs plan-bioiq.json
```

Четвёртый аргумент `restand.sh` обязателен: подмена `PROGRAMDATA` этот виджет не изолирует (раздел 2), и чистить надо `%APPDATA%\kiosk-bioiq`.

## 8. Чего в продукте нет

- **Автоматического обновления.** Новая версия ставится поверх установщиком. Механизма нет на платформе KIOSK в целом.
- **Windows 7 и 8.** Плеер собран на Electron 39, эти системы не поддерживаются с версии 23.
- **Запуска экспортированной викторины без установленного плеера.** Файл `.bioiq.json` самодостаточен по содержимому, но открывает его плеер. Расхождение с ТЗ записано в `bioiq-acceptance-matrix.md` §4.2.
- **Сетевого обмена.** Викторины передаются файлом, сервера у виджета нет.
