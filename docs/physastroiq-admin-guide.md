## 1. Что устанавливается

Виджет входит в состав плеера KIOSK и отдельной установки не требует. В дистрибутиве он занимает:

| Что | Размер |
|---|--:|
| 6 карт игровых уровней (1800×1200 PNG) | ≈ 616 КБ |
| 14 тематических изображений (1600×1100 PNG) | ≈ 1,6 МБ |
| 2 встроенные викторины (JSON) | ≈ 124 КБ |

Виджет открывается **в отдельном окне** (как Типы 7, 9 и 10), а не на общем холсте проекта.

### Требования к системе

- Windows 10 или 11. **Windows 7 и 8 не поддерживаются** — Electron 39 на них не запускается;
- разрешение экрана от 1280×800. Карты уровней рассчитаны на 1800×1200 и масштабируются под окно;
- звуковая карта не обязательна: сигналы «верно»/«неверно» синтезируются, отключаются кнопкой на поле.

## 2. Где лежат данные

```
%APPDATA%\kiosk-physastroiq\
├── userdata.json      история партий, настройки, PIN режима учителя (хеш)
└── quizzes\
    ├── <id>.json      викторины, созданные учителем
    └── <id>-level1.png … изображения их уровней
```

`%APPDATA%` — это `C:\Users\<имя>\AppData\Roaming`.

**Важно: каталог у каждого пользователя Windows свой.** Викторины, созданные под одной учётной записью, в другой не видны. Если за компьютером работают несколько педагогов под разными учётными записями, викторины переносятся экспортом (раздел 3), а не копированием каталога.

**Встроенные викторины «Физика» и «Астрономия» здесь не лежат** — они входят в дистрибутив и не изменяются. Учитель может сделать их копию и править её, оригинал остаётся нетронутым.

### Резервная копия

Достаточно скопировать каталог `%APPDATA%\kiosk-physastroiq` целиком. Восстановление — обратное копирование при закрытом приложении.

## 3. Перенос викторин между компьютерами

1. На исходном компьютере: **Режим учителя** → PIN → у нужной викторины **«Экспорт в файл»**.
2. Сохранить `.physastroiq.json`. Файл самодостаточен: изображения уровней лежат внутри него.
3. На целевом компьютере: **Режим учителя** → PIN → **«Импортировать викторину»** → выбрать файл.

Викторина появится в каталоге под своим названием и получит новый внутренний идентификатор — импорт дважды на одном компьютере даст две независимые копии, а не перезапишет первую.

**Защищённые паролем викторины** переносятся вместе с паролем: на целевом компьютере он потребуется для правки так же, как на исходном.

Проверочный файл для приёмки: `docs/physastroiq-exchange-check.json`.

## 4. Доступ к виджету в редакторе

Виджет виден в библиотеке редактора не всем. Список адресов, которым он доступен, задан в `packages/server/src/config/physastroiqAccess.ts`.

Чтобы открыть доступ ещё одному пользователю, добавьте его адрес в этот список и пересоберите сервер. Проверка идёт по адресу учётной записи, регистр не учитывается.

## 5. Сброс PIN режима учителя

PIN хранится в виде хеша и восстановлению не подлежит — его можно только сбросить.

1. Закрыть приложение.
2. Открыть `%APPDATA%\kiosk-physastroiq\userdata.json`.
3. Найти `"teacherPinHash"` и поставить значение `null`.
4. Сохранить файл, запустить приложение.

При следующем входе в режим учителя PIN будет предложено задать заново. **История партий при этом сохранится** — трогать остальные поля не нужно.

Если файл повреждён и не открывается, его можно удалить целиком: приложение начнёт с чистого состояния и покажет об этом предупреждение на стартовом экране. История партий будет потеряна.

## 6. Разбор неполадок

| Признак | Причина | Что делать |
|---|---|---|
| На стартовом экране предупреждение «не удалось прочитать сохранённые данные» | `userdata.json` повреждён | Приложение уже начало с чистого состояния и работает. Старую историю не восстановить |
| Карта уровня не показывается, поле пустое | Файл карты не попал в сборку | Проверить `packages/player/public/physastroiq/*.png`; при необходимости пересобрать (раздел 7) |
| Импорт викторины ничего не делает | Файл не той викторины (`.bioiq.json`, `.chimiq.json`) | Расширение у каждого виджета своё: нужен `.physastroiq.json` |
| Викторины учителя пропали | Вход под другой учётной записью Windows | См. раздел 2: каталог данных у каждого пользователя свой |
| Переключатель «Физика / Астрономия» не виден | Активной назначена викторина учителя, а не встроенная | Так задумано: переключатель не должен сбрасывать выбор педагога. Вернуть его — назначить активной встроенную викторину в каталоге |
| Виджета нет в библиотеке редактора | Адрес не в списке доступа | См. раздел 4 |

### Журнал

Плеер пишет журнал в `%APPDATA%\kiosk-player\logs\`. Сообщения виджета помечены `[physastroiq]`.

## 7. Пересборка контента

Нужна, только если меняются карты уровней, изображения или банк вопросов. Ни одной координаты руками: карты — единственный источник координат, а сборщик берёт их по имени структуры.

```sh
cd packages/player

# 1. Тематические изображения (14 шт.: 8 физика + 6 астрономия)
node tools/physastroiq/draw-thematic.mjs
env -u ELECTRON_RUN_AS_NODE node_modules/electron/dist/electron.exe \
  tools/physastroiq/render-thematic.cjs "$(pwd -W)/tools/physastroiq/svg" "$(pwd -W)/public/physastroiq/thematic"

# 2. Карты уровней (6 шт.) + координаты структур
node tools/physastroiq/draw-levels.mjs all
env -u ELECTRON_RUN_AS_NODE node_modules/electron/dist/electron.exe \
  tools/physastroiq/render-thematic.cjs "$(pwd -W)/tools/physastroiq/levelsvg" "$(pwd -W)/public/physastroiq"

# 3. Викторины из карт и банков вопросов
node tools/physastroiq/build-content.mjs

# 4. Проверки
npm test
```

### Что упадёт само, если что-то не так

- **`draw-levels.mjs`** обрывается, если кликабельные области налезают друг на друга, выходят за край карты, повторяют идентификатор или если точек без привязки меньше десяти (требование ТЗ);
- **`draw-thematic.mjs`** обрывается, если подпись-выноска не помещается в отведённый столбец. Обрезанная подпись выглядит на картинке как обычный текст, и читатель не узнает, что у слова отрезан хвост;
- **`build-content.mjs`** обрывается, если вопрос ссылается на структуру, которой на карте нет.

### Проверка, которую надо сделать глазами

После любой правки карт:

```sh
node tools/physastroiq/overlay-structures.mjs physics
node tools/physastroiq/overlay-structures.mjs astro
env -u ELECTRON_RUN_AS_NODE node_modules/electron/dist/electron.exe \
  tools/physastroiq/render-thematic.cjs "$(pwd -W)/tools/physastroiq/overlay" "$(pwd -W)/tools/physastroiq/overlay"
```

Инструмент рисует кликабельные области поверх карты, с именами. Просмотрите шесть получившихся PNG: **каждая область должна лежать на своём объекте, а не рядом с ним.** Автоматически это не проверяется — прямоугольник с именем «Луна», лежащий на пустом месте рядом с Луной, для любой проверки безупречен. Отладочные файлы в поставку не едут (каталог `overlay/` в `.gitignore`).

### Воспроизводимость

Перерисовка даёт **побайтово те же файлы**: там, где на картинке нужен беспорядок, используется генератор псевдослучайных чисел с фиксированным зерном. Проверено 18.09.2026 — после полной перерисовки `git status` не показал ни одного изменения.

## 8. Чего в продукте нет

Перечислено, чтобы вопросы не возникали на приёмке. Подробности — в `physastroiq-acceptance-matrix.md`, раздел 4.

- **Windows 7 и 8.** Плеер на них не запускается;
- **запуск экспортированной викторины без установленного продукта.** Файл `.physastroiq.json` открывается плеером KIOSK, сам по себе не запускается;
- **обновление исполняемого файла.** Встроенный механизм обновления есть, но он обновляет содержимое проекта с сервера; новая версия приложения ставится переустановкой;
- **отдельные картинки к каждому вопросу встроенных викторин.** Механизм в редакторе есть и работает, но в поставке все 180 вопросов решаются на картах уровней;
- **проверка правильности вопросов.** Приложение одинаково исправно засчитает и верный ответ, и неверный, если так написано в банке.
