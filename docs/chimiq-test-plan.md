# Программа и методика испытаний: виджет «ХимIQ» (Тип 9)

**Документ требуется ТЗ:** приёмка проводится по трассируемой матрице требований (`docs/chimiq-acceptance-matrix.md`); этот документ описывает, КАК проверять каждое требование руками.

**Состояние на 15.09.2026.** Прогоны, уже выполненные разработчиком (живой CDP-прогон на реально собранном `.exe`, см. `docs/chimiq-acceptance-matrix.md` §6), отмечены — но приёмка проводится заново приёмщиком: прогон разработчика доказывает, что механизм работает, а не что он годится для занятия.

---

## 0. Подготовка

1. Установить сборку плеера с проектом, содержащим виджет `chimiq`.
2. Убедиться, что `%AppData%\kiosk-chimiq` (внимание: персональный каталог на пользователя Windows, не `%ProgramData%` — см. `docs/chimiq-admin-guide.md` §1) **отсутствует или пуст** — испытания начинаются с чистого устройства.
3. Приготовить: картинку (PNG/JPEG/GIF/WebP) для своей викторины, второй компьютер с той же сборкой (для проверки обмена викторинами).

**Признак чистого старта:** интро-экран без предупреждения о повреждённых данных, каталог викторин (после первого входа в режим учителя) содержит только встроенную «Химию».

## 2. Партия: настройка и прохождение (FR-002, FR-006, FR-007, FR-009, FR-019, строки 241, 245, 246, 248, 258)

| № | Действие | Ожидаемый результат |
|---|---|---|
| 2.1 | «Играть!» → выбрать 1 игрока | Переход к вводу имени, поле предзаполнено «Игрок 1» |
| 2.2 | Очистить имя и нажать «Далее» | Кнопка неактивна, текст «Введите имя для каждого игрока» — пустое имя не пропускает дальше |
| 2.3 | Ввести имя, «Далее» → выбрать уровень «Начинающий» | Переход к выбору числа вопросов: варианты 5/10/15 (или меньше, если вопросов в пуле не хватает) |
| 2.4 | Выбрать 5 вопросов | Игровое поле: картинка уровня, кликабельные клетки, таймер, счёт |
| 2.5 | Дождаться истечения таймера, не отвечая | Засчитан неверный ответ (0 очков), переход к следующему вопросу — таймер не виснет |
| 2.6 | Кликнуть заведомо неверную клетку | Подсветка красным, засчитан неверный ответ |
| 2.7 | Кликнуть верную клетку сразу | Подсветка зелёным, максимум очков за вопрос (полное значение веса) |
| 2.8 | Кликнуть верную клетку ближе к истечению времени | Очков меньше, чем в 2.7 — начисление убывает со временем |
| 2.9 | Нажать «Сдаюсь» | 0 очков за вопрос, переход дальше без клика по полю |
| 2.10 | Повторить весь уровень 2, 3 игроками | Ходы строго по очереди, счёт у каждого свой |
| 2.11 | Открыть подсказку у вопроса | Текст подсказки показывается по кнопке, не сама — до нажатия её не видно. Кнопка подсказки должна быть доступна на КАЖДОМ вопросе, не только у некоторых (закрытый баг 2026-09-15 — у 153 из 168 встроенных вопросов подсказки не было) |
| 2.12 | Пройти партию целиком | Экран «Результаты»: таблица по игрокам (очки, верных/всего) |
| 2.13 | Нажать «Подробнее» у игрока | Список вопрос-за-вопросом с пометкой верно/неверно и очками, «Назад к результатам» возвращает |

**Отдельно проверить (регрессия 15.09.2026, жалоба «только некоторые иконки можно нажать, хотя их в разы больше»):** посчитать число кликабельных плиток на игровом поле (`document.querySelectorAll('[aria-label="correct-point"], [aria-label^="decoy-"]').length` через консоль разработчика или живой CDP-замер) и сравнить с числом визуально различимых плиток на картинке уровня — числа должны совпадать. Кликнуть по ЛЮБОЙ визуально отличимой плитке (не только по одной из исходных 15 общих decoy) и убедиться, что она реагирует подсветкой и засчитывает ответ, а не остаётся мёртвой зоной.

**Отдельно проверить: кнопка «🔍 Крупнее» на игровом поле.** Нажать — картинка и точки должны увеличиться (примерно в 1.6 раза от исходного пиксельного размера), появляется возможность прокрутки, если поле не помещается целиком. Кликнуть по увеличенной точке — клик должен засчитываться так же корректно, как при обычном размере (позиции точек считаются в процентах от размера картинки, не в абсолютных пикселях — масштаб их не ломает). Повторное нажатие («Обычный размер») возвращает исходный масштаб. **Проверить сохранение (2026-09-15):** включить «Крупнее», доиграть партию до результатов, начать новую партию — поле должно открыться уже увеличенным без повторного нажатия кнопки.

**Отдельно проверить: звуковая обратная связь (2026-09-15).** По умолчанию звук включён — клик по верному ответу должен звучать восходящей трелью, по неверному — нисходящим гудком (различимы на слух по направлению). Кнопка «🔊 Звук» / «🔇 Звук выкл.» отключает оба звука без остановки самой игры. Выключенное состояние, как и «Крупнее», должно сохраняться между партиями.

**Отдельно проверить видимость поля (регрессия 15.09.2026, см. `docs/chimiq-acceptance-matrix.md` §6):** пройти все 3 уровня на маленьком окне и на полноэкранном — **все клетки, включая правильный ответ, должны быть видны без обрезки и без прокрутки**. Раньше на уровнях 2/3 до 8 из 16 клеток физически уходили за нижний край окна.

**Отдельно проверить: иллюстрация над текстом вопроса (закрытие FR-008/FR-015, 2026-09-16).** Пройти подряд 10-15 вопросов на любом уровне — **у каждого вопроса без исключения должна быть картинка** над текстом (не пустое место). Убедиться, что картинка не поломана (`complete: true`, `naturalWidth > 0` через консоль/CDP) и что она нейтральная по смыслу — не выдаёт и не подсказывает конкретный ответ вопроса (см. разбор конкретных примеров в `docs/chimiq-question-illustrations-decision.md`, почему выбрана именно тематическая, а не персональная иллюстрация под ответ). Отдельно проверить свою викторину педагога с загруженной через редактор картинкой вопроса — должна показываться ИМЕННО ОНА, а не тематическая заглушка.

## 3. Режим учителя: PIN (FR-016, строка 255 — часть про доступ к разделам)

| № | Действие | Ожидаемый результат |
|---|---|---|
| 3.1 | На чистом устройстве нажать «Режим учителя» | Экран «Задайте PIN режима учителя», два поля ввода (PIN + подтверждение) |
| 3.2 | Ввести PIN из 3 цифр | Отказ: «PIN должен состоять ровно из 4 цифр» |
| 3.3 | Ввести 4 цифры, в подтверждении — другие 4 цифры | Отказ: «PIN и подтверждение не совпадают», поле подтверждения очищается |
| 3.4 | Ввести одинаковый 4-значный PIN дважды, «Задать» | Открывается каталог викторин |
| 3.5 | Выйти, снова «Режим учителя», ввести **неверный** PIN | Отказ: «Неверный код» |
| 3.6 | Ввести правильный PIN | Каталог открывается |
| 3.7 | Перезапустить приложение, повторить 3.6 | PIN сохранился между запусками |

**Отдельно (см. `docs/chimiq-admin-guide.md` §2):** удалить `userdata.json` и повторить с 3.1 — приложение снова просит задать PIN (сброс подтверждён), но **вместе с этим пропадает и вся история партий** — проверить, что статистика по дням (раздел 5 ниже) после этого пуста.

| № | Действие | Ожидаемый результат |
|---|---|---|
| 6.1 | «Экспорт в файл» у своей викторины | Системный диалог сохранения, файл `<название>.chimiq.json` |
| 6.2 | Перенести файл на ДРУГОЕ устройство с тем же плеером, «Импортировать викторину» | Викторина появляется в каталоге со всеми тремя картинками уровней и картинками вопросов (если были) |

## 8. Что этой программой НЕ проверяется

- **Методическая точность 168 вопросов.** Оригинальный текст, написанный в этом проекте, без участия профильного эксперта-химика — см. `docs/chimiq-acceptance-matrix.md` §4.4.
- **Пригодность интерфейса для сенсорного экрана/интерактивной доски руками ребёнка** — прогон делался кликом мыши через CDP и вручную на обычном мониторе.
- **Android.** Версии нет.
- **Нагрузочное/долговременное хранение** большого числа своих викторин или очень длинной истории партий за много месяцев.
