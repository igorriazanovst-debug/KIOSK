# Матрица трассировки требований: виджет «Инофон» (Тип 4)

**Документ требуется ТЗ:** приёмка проводится по трассируемой матрице требований — каждое FR должно иметь не менее одного тест-кейса.

**Состояние на 16.09.2026.** Каждая строка отвечает на три вопроса: что требуется, чем закрыто, чем это проверено. Строка считается закрытой только если способ проверки указан конкретно — «реализовано» без теста или живого прогона закрытием не считается.

**Источник требований:** ТЗ по Типу 4, строки 84–98. Колонка «ИСТ» — номер строки исходной закупочной спецификации.

**Программа испытаний:** `docs/inophone-test-plan.md`. Автоматический прогон — `ino-accept.mjs` (разделы 1–9) и `ino-robust.sh` (раздел 10).

## Условные обозначения

| Знак | Значение |
|:--:|---|
| ✅ | Закрыто и проверено указанным способом |
| ⚠️ | Закрыто частично: что именно осталось — в колонке «Чем проверено» |
| ❌ | Не закрыто |
| — | Закрывается не кодом виджета (платформой, договором, составом контента) |

## 4. Открытые расхождения

1. **Башкирский словарь не выверен носителем.** 444 слова написаны по доступным источникам; часть из них совпадает с русским написанием. Список на проверку — `docs/inophone-bashkir-review.md`. До проверки соответствие ТЗ по этому языку — **заявленное, а не подтверждённое**. Программой испытаний это не закрывается: приложение одинаково исправно произнесёт и верное слово, и неверное.

2. **Башкирская озвучка сделана моделью с некоммерческой лицензией.** 16.09.2026 башкирский переозвучен голосом Silero (`ba/v2_aigul`, обучен на живой речи) вместо формантного eSpeak. Качество несравнимо выше, но модель под CC BY-NC-SA 4.0; у единственной альтернативы с башкирским (Meta MMS) то же ограничение. Прежние файлы eSpeak сохранены, возврат — одна команда. Подробности и таблица вариантов — в `inophone-third-party-licenses.md`, раздел 3.

3. **Остальные языки тоже синтезированы.** Русский и английский — Windows SAPI, теми же голосами, что Типы 2 и 3; французский, немецкий и китайский — eSpeak NG. Разборчивость проверяется ухом методиста.

4. **Потолок изучаемых языков — три.** ТЗ верхней границы не задаёт. Ограничение принято по месту на карточке объекта: четыре строки перевода под картинкой перестают читаться с расстояния доски.

5. **Правовая сторона контента.** Иллюстрации нарисованы нейросетью, речь синтезирована. ТЗ раздел 10 требует обеспечить законность всех используемых изображений и аудио — вопрос к договору, не к коду.

6. **Windows 7/8 и Android** — см. FR-004. Вынесено за рамки по решению пользователя.

7. **Автообновление** — см. FR-017. Делается один раз на всю платформу, отдельной работой.
