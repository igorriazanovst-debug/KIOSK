# Решение по FR-008/FR-015 (изображение к каждому вопросу): 2026-09-16

**Статус: реализовано.** ТЗ (строки 247, 254) буквально требует изображение
к КАЖДОМУ вопросу. До этой сессии этого не было вообще (только общая
картинка-карта уровня) — см. `docs/chimiq-acceptance-matrix.md`, было ⚠️.

## Почему не персональная иллюстрация под каждый из 168 ответов

Первая попытка — нарисовать иллюстрацию под конкретный ответ каждого
вопроса (как буквально читается ТЗ). Сделано 5 примеров для проверки
подхода, прежде чем тратить время на все 168:

| Вопрос | Иллюстрация | Проблема |
|---|---|---|
| «Химическая формула воды?» | молекула с подписями O/H | **прямой спойлер** — подписи и есть ответ |
| «Символ серы?» | плитка таблицы с буквой «S» | **прямой спойлер** — буква и есть ответ |
| «Центральная часть атома?» | диаграмма атома с подписью «Ядро» | **прямой спойлер** — подпись и есть ответ |
| «Центральная часть атома?» (без подписи, для сравнения) | тот же атом, ядро просто крупнее/цветом выделено | **спойлер остаётся** — какая часть «особенная», всё равно видно визуально, подпись не главное |
| «В какой посуде удобно нагревать и смешивать растворы?» | рисунок именно колбы | **сильная подсказка** — показан ровно тот предмет, который является ответом |
| «Прибор для взвешивания веществ?» | рисунок весов | **сильная подсказка** — тот же класс проблемы |

**Вывод**: это не вопрос аккуратности рисунка — структурное свойство
вопросов вида «как это называется» (подавляющее большинство банка):
любая точная иллюстрация ответа либо содержит его буквально, либо
показывает ровно тот предмет/факт, который является ответом.
Персональные иллюстрации под ответ сделали бы часть вопросов
тривиальными (угадывается по картинке, не по знанию) — решение
пользователя: **не делать так**.

## Реализованное решение: нейтральная иллюстрация по ТЕМЕ, не по ответу

`src/chimiq/questionThemeImages.ts` — 6 нейтральных изображений (по одной
на каждую из 6 тем банка), не привязанных к конкретному вопросу/ответу:

| Тема | Файл | Что изображено |
|---|---|---|
| Экспериментальная химия | `experimental.png` | силуэты лабораторной посуды (колба/пробирка/стакан), без подписей |
| Химические элементы | `elements.png` | обобщённая сетка цветных плиток без символов |
| Строение атома | `atom.png` | орбиты и ядро без подписи |
| Химические соединения | `compounds.png` | абстрактная молекула-граф (не конкретное вещество) |
| История химии | `history.png` | книга + колба — обобщённый мотив «наука прошлого» |
| Таблица Менделеева | `periodic.png` | сетка мини-плиток без символов, декоративная |

**Каждый из 168 вопросов при показе на игровом поле получает
изображение** (`GameBoardScreen.tsx`: `questionThemeImageUrl(currentQuestion.theme)`,
запасной вариант, когда `question.questionImage` не задан — у встроенной
викторины он не задан никогда) — буква требования выполнена, при этом
ни одно изображение не спойлерит конкретный ответ, потому что оно общее
на ~28 вопросов темы, а не на один вопрос.

**Механизм НЕ использует** `question.questionImage` + `chimiqItemImageUrl`
(`chimiqmedia://item/...`) — этот протокол резолвит путь против
`%AppData%/kiosk-chimiq/quizzes/` (папка ЗАГРУЖЕННЫХ через редактор
изображений пользовательской викторины), а не против `public/`, где
лежат бандловые ассеты встроенной викторины — обращение по этому пути
для builtin-контента дало бы 404. Использован тот же приём, что уже есть
у `levelImageUrl` — плоский относительный путь в `public/chimiq/`.

**Свои викторины педагога не затронуты**: если учитель загрузил
`questionImage` через редактор — показывается ОНА (существующее
поведение не изменилось); тематическая картинка — только запасной
вариант, когда своя не задана.

4 теста (`questionThemeImages.test.ts`), включая проверку, что каждая
тема, реально используемая в банке, имеет картинку, и что путь — НЕ
`chimiqmedia://` (иначе для builtin quiz это была бы регрессия в 404).
Живая CDP-проверка: 12 подряд вопросов на уровне 3 (самом плотном по
тексту) — у каждого своя тематическая картинка загрузилась
(`complete: true`, `naturalWidth: 440`, ни одной поломанной), картинка
верно соответствует теме вопроса.
