**Вывод по программной части:** все компоненты под MIT либо Apache-2.0. Оба разрешают коммерческое использование и распространение в составе продукта. Обязательство одно и общее для обеих лицензий: сохранять текст лицензии и уведомление об авторских правах в поставке. `electron-builder` включает лицензии зависимостей в дистрибутив автоматически — **проверить наличие файла лицензий в собранном `.exe` перед сдачей**.

Отдельно про Electron: сам Electron под MIT, но включает Chromium (BSD-3-Clause и набор лицензий компонентов) и Node.js (MIT). Полный перечень идёт в самой поставке Electron (`LICENSES.chromium.html`) и попадает в дистрибутив вместе с ним.

## 2. Учебный контент

**Состояние на 11.09.2026: поставочного контента нет.** В `packages/words-library` лежат заглушки — SVG-фигуры, сгенерированные скриптом `tools/generate-placeholders.mjs`, озвучки нет вовсе. Заглушки созданы в рамках этого проекта, права на них принадлежат разработчику, но к приёмке они не годятся ни в каком виде.

### Что должно быть заполнено к приёмке

По ТЗ требуется ≥ 250 озвученных слов с иллюстрациями и ≥ 15 тем (план берёт с запасом: 270 и 15). На **каждый** материал должна быть запись в реестре ниже.

| Материал | Автор / источник | Лицензия или основание | Дата получения | Файлы |
|---|---|---|---|---|
| _(заполняется по мере производства контента)_ | | | | |

### Обязательные правила ведения реестра

1. **Ресурсы эталона ОС3 («Я знаю много слов» версии 1.7.3) использовать нельзя ни в каком виде** — ни иллюстрации, ни озвучку, ни интерфейсные значки. Разбор эталона служил источником сведений о поведении продукта, а не источником материалов.
2. Для заказных материалов основание — договор с исполнителем с передачей исключительных прав либо лицензии, достаточной для распространения в составе коммерческого продукта.
3. Для стоковых материалов недостаточно «бесплатно для личного использования»: нужна лицензия, разрешающая коммерческое распространение в составе ПО. Ссылку на условия лицензии сохранять вместе с датой — условия у стоков меняются.
4. Для шрифтов проверять отдельно: право на встраивание в приложение (embedding) не следует автоматически из права на использование в макете.
5. Голоса дикторов: письменное согласие на использование записи в составе продукта, распространяемого неограниченному кругу образовательных организаций.
