# «ФизАстроIQ»: викторина без установки — мини-проигрыватель и таблица Excel

**Зачем это.** ТЗ, FR-019 (строка 340): «экспорт викторины в отдельный файл для запуска викторины на любом компьютере». Основное приложение требует установки и активации; урок в соседнем кабинете, открытый урок в другой школе, домашний компьютер ученика — там его нет. Мини-проигрыватель закрывает именно эти случаи.

**Что это.** Два файла в одной папке:

| Файл | Что в нём |
|---|---|
| `player.html` | Проигрыватель. Один файл, около 330 КБ. Открывается двойным щелчком в любом браузере. Не требует установки, прав администратора и интернета |
| `*.xlsx` | Викторина: таблица Excel с текстом вопросов. Картинок, схем и карт в ней нет — только текст |

Файл викторины **никуда не отправляется**: проигрыватель читает его прямо на компьютере, а сетевые запросы ему запрещены на уровне страницы (политика `connect-src 'none'`).

---

## 1. Как провести викторину

1. Скопируйте оба файла в любую папку или на флешку.
2. Откройте `player.html` двойным щелчком.
3. Нажмите на область «Выберите файл викторины» (или перетащите в неё `.xlsx`).
4. «Играть!» → число игроков (1–3) и имена → уровень → сколько вопросов каждому → «Начать».
5. Игроки отвечают по очереди, выбирая один из четырёх вариантов — мышью, пальцем на интерактивной панели или клавишами **1–4**.

Правила те же, что в основном приложении: у вопроса есть вес, очки убывают вместе с таймером, «Показать подсказку» помогает рассуждать, «Сдаюсь» пропускает вопрос. После ответа проигрыватель показывает знак ✓ или ✗ и правильный вариант — не только цветом, так что результат различим при любом восприятии цвета. В конце — таблица мест и раскрывающаяся детализация по каждому игроку.

## 2. Готовые викторины

| Файл | Вопросов | Уровни | Содержание |
|---|--:|---|---|
| `physastroiq-astronomy-390.xlsx` | **390** | 132 / 132 / 126 | Солнечная система, планеты и малые тела, Луна, фазы и затмения, созвездия и ориентирование, Солнце и звёзды, галактики и Вселенная, небесная сфера, время и календарь, телескопы и методы, история астрономии и космонавтика |
| `physastroiq-physics-90.xlsx` | 90 | 30 / 30 / 30 | Электрическая цепь и действия тока, измерительные приборы, простые механизмы, силы и равновесие, колебания, линзы, отражение, преломление и дисперсия |

У каждого вопроса — три написанных вручную неверных варианта и подсказка. Как банк проверялся — в `physastroiq-text-bank-review-2026-09-20.md`.

**Из приложения.** В режиме учителя, в каталоге викторин, у каждой викторины есть кнопка **«Без установки»**: она сохраняет в выбранную папку таблицу и кладёт рядом `player.html`. У встроенных викторин выгружается готовый текстовый банк из таблицы выше. У своей викторины — её вопросы, ответы и подсказки; карты, координаты и картинки не выгружаются, а неверные варианты проигрыватель подберёт сам (см. ниже). Если в папке уже лежит чужой `player.html`, он не затирается: проигрыватель сохраняется как `player-physastroiq.html`.

## 3. Как устроена таблица — и как сделать свою

Лист **«Вопросы»**, первая строка — названия столбцов (порядок и регистр не важны):

| Столбец | Обязателен | Что писать |
|---|:--:|---|
| Вопрос | да | Текст вопроса |
| Ответ | да | Правильный ответ |
| Уровень | нет | 1, 2 или 3 (Начинающий, Опытный, Профессионал). Пусто — 1 |
| Тема | нет | Любое название; показывается над вопросом |
| Неверный 1, Неверный 2, Неверный 3 | нет | Неверные варианты |
| Подсказка | нет | Если пусто, кнопки подсказки у вопроса не будет |
| Вес | нет | Очки за мгновенный верный ответ. Пусто — 100 / 130 / 170 по уровням |
| Время, с | нет | Секунд на ответ. Пусто — 35 / 30 / 25 по уровням |
| № | нет | Для удобства, проигрыватель его не читает |

Необязательный лист **«О викторине»**: строки «Название» и «Описание».

**Если неверные варианты не заполнены,** проигрыватель доберёт их из ответов на другие вопросы: сначала той же темы и уровня, затем того же уровня, затем любых. Поэтому даже таблица из двух столбцов «Вопрос — Ответ» — уже рабочая викторина, если вопросов в ней несколько. Порядок вариантов перемешивается при каждом показе.

**Ошибки в таблице** проигрыватель называет по номерам строк Excel: «Строка 17: нет ответа». Строки с ошибками пропускаются, на остальных можно играть. «ё» и «е», прописные и строчные при сравнении вариантов считаются одинаковыми: «все» и «всё» в одном вопросе — повтор.

Ограничения: файл до 2 МБ, до 2000 вопросов, текст ячейки до 500 знаков, формат `.xlsx` (старый `.xls` нужно пересохранить).

## 4. На чём работает

Любой браузер, выпущенный примерно с 2018 года: Chrome, Edge, Firefox, Яндекс Браузер, Safari — на Windows (включая Windows 7 с установленным браузером), Linux, macOS, а также на интерактивных панелях с Android. В более старых браузерах проигрыватель тоже открывается: шрифты и отступы становятся проще, игра работает.

## 5. Для разработчика

Исходники — `packages/quiz-mini-player`:

```sh
cd packages/quiz-mini-player
npm install                      # один раз: SheetJS 0.20.3 с cdn.sheetjs.com
npm test                         # логика, правила банка, сам банк, собранные xlsx
node build.mjs                   # src/* + SheetJS → release/player.html
node tools/build-bank.mjs        # bank/**/*.json → release/*.xlsx (падает на нарушениях правил)
node tools/sync-to-player.mjs    # копии поставки → packages/player/electron/physastroiq/standalone
```

- `src/quizCore.js` — вся логика без экрана (разбор таблицы, варианты, партия); один и тот же файл вшивается в HTML и проверяется тестами в Node.
- `src/app.js` — экраны. Текст из таблицы попадает в страницу только через `textContent`; `innerHTML` в коде нет.
- `build.mjs` — вшивает стиль, библиотеку и скрипты в один файл и строит политику CSP с хэшем каждого блока: выполнится только то, что вшито при сборке.
- `bank/bankRules.js` — правила качества банка (утечка ответа в вопрос и подсказку, перекос длины верного варианта, род вариантов, дубли, нестабильные факты, баланс уровней). Правила пишутся вместе с банком: `bank/AUTHORING.md`.
- Файлы в `release/` и их копии в плеере **побайтно значимы** (хэши CSP), поэтому помечены в `.gitattributes` как `-text`; расхождение копий с источником ловит `electron/physastroiq/standaloneExport.test.js`.
