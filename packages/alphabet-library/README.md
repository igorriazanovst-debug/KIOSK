# alphabet-library — пакет контента виджета «АзбукоСлов» (Тип 3)

**Иллюстрации здесь — ЗАГЛУШКИ, озвучка СИНТЕЗИРОВАНА.** Игру можно показывать и проверять руками; для приёмки этого недостаточно.

Заглушки не притворяются рисунками: абстрактная фигура на цветном поле и подпись «заглушка». Различимы между собой все 95 — фигура, наклон и цвет выводятся из идентификатора. Это условие проверки, а не украшательство: на всех трёх этапах выбирают из нескольких карточек, и будь они одинаковы, живой прогон не доказал бы ничего.

> **Заглушка не несёт ни буквы, ни названия слова.** Первая версия рисовала первую букву крупно в круге и подписывала словом — на этапе «покажи букву» это был ответ, напечатанный на карточке. Заглушка не должна давать того, чего не даст настоящий рисунок: узнать слово по изображению и есть задание.
>
> Отсюда следствие: **с заглушками игра осмысленна только со звуком.** Так и задумано — слово несут картинка и озвучка, а пока картинки условные, его несёт одна озвучка.

### Почему синтезированная озвучка не годится для поставки

Пайплайн перенесён из Тип 2 (Windows SAPI → ffmpeg), где он отработал сначала на 2835 файлах «Матемашки». Здесь им сделаны **372 файла, 3,2 МБ**.

Синтез — **средство разработки**: он делает игру проверяемой на слух и позволил замерить реальный вес звука. ТЗ (строка 79) требует «озвученные слова», не уточняя способ; пригоден ли синтезированный голос для пособия по развитию речи, решает заказчик или методист, а не разработчик. Перед поставкой файлы заменяются записью живым голосом — схема, раскладка и имена файлов при этом не меняются.

## Что должно здесь оказаться к приёмке

ТЗ строка 79 (FR-016) требует **≥ 160 озвученных слов с иллюстрациями**, строка 71 (FR-008) — **≥ 2 иллюстрации на каждую букву**.

Сейчас: **95 слов, 151 слог, 33 буквы по 3 слова, 372 файла озвучки**. Требование строки 71 выполнено с запасом — ни одной буквы на границе. Требование строки 79 **не выполнено**: до 160 слов не хватает 65, и озвучка синтезирована, а не записана.

Запас по строке 71 взят осознанно. У эталона ОС3 буквы **Ё** и **Й** имеют ровно по 2 иллюстрации, и разбор назвал это риском приёмки: любое сокращение контента ломает соответствие. Здесь у каждой буквы по три слова.

ТЗ раздел 10 требует обеспечить законность использования всех изображений, аудио и шрифтов. Значит:

- ресурсы ОС3 использовать нельзя ни в каком виде;
- на каждый материал должен быть источник и лицензия — реестр ведётся вместе с пакетом.

**Словарь написан здесь, а не взят у эталона** (`tools/catalogue.mjs`). Сами слова — обиходные русские существительные, и совпадения с чужим списком неизбежны и безобидны; заимствовано только устройство каталога, которое и не может быть иным.

## Устройство пакета

`index.json` — манифест, единственный источник правды о составе:

```jsonc
{
  "schemaVersion": 1,
  "audioScheme": { "recorded": false },
  "letters":   [{ "number": 1, "name": "А", "wordIds": ["arbuz", "avtobus", "apel_sin"] }],
  "syllables": [{ "id": "av", "name": "ав", "letterNumbers": [1, 3] }],
  "words":     [{ "id": "avtobus", "name": "Автобус",
                  "syllableIds": ["av", "to", "bus"], "hasWithoutLastSyllable": true }],
  "sets":      [{ "id": "transport", "title": "Транспорт и дорога", "wordIds": ["avtobus"] }]
}
```

Раскладка файлов (`packages/shared/src/alphabet/model/resources.ts`):

```
assets/img/<id>.svg            иллюстрация слова
assets/media/<id>.mp3          слово целиком
assets/media/<id>_bgn.mp3      слово без последнего слога
assets/media/<номер>.mp3       произношение буквы, 1.mp3 … 33.mp3
assets/media/<слог>.mp3        произношение слога
```

### Слова, слоги и буквы делят один каталог `media/`

Это черта эталонной раскладки, и она же её слабое место. Односложное слово «Йод» (`jod`) и слог `jod` дают ОДИН путь; слог с идентификатором `1` забрал бы путь буквы «А». Сборка не падает — файл просто перезаписывается последним, — а проявится это на занятии, где слово прозвучит чужим слогом.

`checkPathCollisions` ловит это обязательной проверкой. Коллизия односложного слова с его же единственным слогом помечена **безвредной**: это один и тот же звук, и общий файл здесь экономия.

### Три буквы особые

**Ъ, Ы и Ь не могут начать слово**, поэтому у них перечисляются слова, где буква стоит внутри: Подъезд, Рыба, Медведь. Иначе требование ТЗ строки 71 для них было бы невыполнимо в принципе.

Отсюда следствие: одно слово законно стоит у двух букв. Слово при этом **обязано** стоять у своей первой буквы — иначе этап «покажи букву» никогда его не предложит, хотя в пакете оно есть. Сборщик дописывает эту связь сам: забыть её при добавлении слова слишком легко.

### Транслитерация

Правила эталона (`avtobus`, `apel_sin` — мягкий знак `_`, `mysh_`) с одним дополнением: **Э даёт `eh`, а не `e`**. Без этого слог «э» из «э-лек-трич-ка» и слог «е» из «е-нот» получают один идентификатор, а значит один файл `media/e.mp3` на два разных звука.

### `audioScheme.recorded` выставляет СБОРЩИК, а не человек

Иллюстрации и озвучка делаются разными людьми и в разные сроки, поэтому `recorded: false` — законное состояние: `expectedLibraryFiles` при нём требует только картинки.

**Объявить озвучку записанной можно только при полном наборе файлов**, и это проверяет сам сборщик. Манифест, объявивший звук, которого нет, — худший исход: подпись «озвучка ещё не записана» с экрана исчезает, кнопка становится активной, и ребёнок видит молчащую карточку без объяснения. Отсутствующий файл очередь воспроизведения не роняет — именно поэтому такой дефект дожил бы до занятия.

## Перегенерировать иллюстрации

Нужны открытый Chrome с отладочным портом и выполненным входом в SYNTX, плюс `ffmpeg`.

```
# 1. генерация: каждая картинка в своём чате, прогон резюмируемый
node tools/generate-illustrations.mjs <порт CDP> <каталог jpg> [сколько]

# 2. вырезание фона и упаковка в файлы пакета
node tools/make-illustrations.mjs <каталог jpg> . <путь к ffmpeg.exe>

# 3. пересборка манифеста
node tools/build.mjs
```

### Что важно знать

**Описания важнее промпта.** `tools/illustration-prompts.mjs` говорит, ЧТО именно видно на карточке, а не повторяет слово: «ёршик» бывает для посуды, для бутылок и рыбой. Если картинку можно назвать двумя словами, задание ломается — ребёнок скажет «пёс», а ответ ждут по «щенку». Поэтому в описании всегда есть признак, отсекающий синоним.

**Три слова нарисовать однозначно нельзя в принципе** — «Еда», «Йога», «Съёмка». Для них выбрана сцена, которую ребёнок назовёт именно этим словом: тарелка с едой читалась бы как «тарелка», поэтому взят накрытый стол.

**Каждая картинка — в своём чате.** Продолжение в одном чате картинок не порождает вовсе (проверено дважды в Тип 2). Перед запросом скрипт уходит на чистый адрес модели.

**Прогон резюмируемый и рассчитан на обрыв.** 95 генераций по полторы-две минуты — это около трёх часов. Готовый файл пропускается.

**Ожидание — до пяти минут на картинку.** Замерено: обычно приходит за 90 секунд, но под нагрузкой сервиса очередь растягивается. Прежнее ожидание в 150 секунд давало ложные сбои.

**Аргумент «сколько» считает ПОПЫТКИ, а не успехи.** Первая версия считала успехи, и пробный прогон «на одну картинку» при трёх неудачах подряд молча пошёл по списку и сжёг девять минут.

**Отправка — через `el.click()`, а не настоящим кликом по координатам.** Настоящий клик по кнопке отправки здесь не срабатывает. Признак успеха один надёжный — очистившееся поле ввода; проверять `disabled` бесполезно, это гонка с перерисовкой Vue.

**Текст промпта кладётся нативным сеттером с событием `input`.** Клик для фокуса ненадёжен: страница подмешивает баннеры сверху и сдвигает вёрстку между замером координат и самим кликом.

### Вырезание фона

Модель просят рисовать на `#FF00FF` — цвете, которого в детской иллюстрации не бывает, — и `colorkey` превращает его в прозрачность.

**Порог 0.36, а не 0.30, как в Тип 2.** При 0.30 по краю оставалась пурпурная кайма от артефактов JPEG. Опасение «выше нельзя, съест тёмные контуры» проверено замером: непрозрачная площадь при 0.30 — 210 448 пикселей, при 0.36 — 210 105, то есть теряется 0,16 %. При 0.42 потери уже 2,6 % — вот там контуры действительно страдают.

Дальше картинка обрезается квадратом по непрозрачной области (карточки в игре квадратные) и кладётся в svg-обёртку как `data:image/webp`.

## Перегенерировать озвучку

Нужны собранный `@kiosk/shared` и `ffmpeg` с `libmp3lame`.

```
node tools/plan-narration.mjs --out tools/narration-plan.json
powershell -ExecutionPolicy Bypass -File ../words-library/tools/generate-narration.ps1   -PlanFile tools/narration-plan.json -PackageRoot assets -FfmpegPath <путь к ffmpeg.exe>
node tools/build.mjs
```

**Генератор общий и живёт в `words-library/tools`** — он полностью параметризован и ничего не знает про виджет. Копии здесь нет намеренно: двести строк тонкостей (зависшая служба Windows Audio, резюмируемый прогон, нормализация громкости) разошлись бы между копиями. Когда он понадобится третьему пакету, его стоит поднять в общий каталог.

Планировщик **спрашивает пути у домена**, а не собирает их строками: иначе генератор и проверка комплектности разойдутся, файлы лягут на диск, а игра молча не будет их находить. В Тип 2 это однажды и случилось.

**Буква озвучивается ЗВУКОМ, а не названием:** «м», не «эм». Иначе «М-А-М-А» складывается в «эм-а-эм-а».

**«Без последнего слога» — не склейка слоговых записей:** синтезатору даётся текст начала слова целиком («авто»), чтобы интонация не рассыпалась на перечисление.

## Пересобрать пакет

```
node tools/build.mjs
```

Перезаписывает `assets/img/` и `index.json` целиком. Словарь правится в `tools/catalogue.mjs`.

Сборщик падает, если два разных слога или два разных слова дают один идентификатор — то есть если пакет собрался бы с одним файлом на два звука.

## Проверка пакета

Целостность графа, комплектность файлов и требование ТЗ строки 71 проверяет домен (`@kiosk/shared`, пространство имён `alphabet`). Плеер выполняет их на старте и пишет в лог, но **занятие из-за них не роняет**: у педагога на устройстве уронить урок из-за одного недостающего файла хуже, чем провести его без этого файла. Жёсткими эти проверки должны быть на сборке пакета.
