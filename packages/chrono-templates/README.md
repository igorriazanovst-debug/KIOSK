# packages/chrono-templates

Готовые шаблоны «Хронолинии», вшиваемые в сборку `player` (через
`extraResources`) и показываемые как read-only галерея в `editor-web`
(Фаза 7 плана — `Хронолайнер_план_реализации.md`).

Не npm-пакет: здесь нет `package.json`/кода, только данные. `player` и
`editor-web` читают эту папку каждый на этапе своей сборки, относительным
путём, без symlink.

## Формат

Каждый файл `*.chrono.json` — валидный `ChronoProject`
(`packages/shared/src/chrono/model/schema.ts`), проходящий
`parseChronoProject()`. Оба потребителя обязаны парсить файлы именно через
эту функцию, а не читать JSON напрямую как доверенные данные.

## Правила

- Имя файла: `NN-slug.chrono.json`, где `NN` — порядок в галерее.
- Без тяжёлых медиа-вложений (у `ChronoProject.media` — только метаданные,
  сами файлы медиа сюда не входят).
- Заголовок карточки в галерее берётся из поля `name` документа —
  отдельный манифест не нужен.
