# Каталог контента «Инофон»

Один файл на тему. Каждый файл отдаёт `{ id, titles, scenes }`, где сцена —
это `{ id, titles, words: [...] }`, а слово — `{ id, ru, en, fr, de, zh, ba }`.

**Слово принадлежит ОДНОЙ сцене.** Повторы между сценами запрещены и ловятся
сборкой: одно и то же понятие, размеченное на двух сценах, даёт ученику
задание, которое он уже проходил, и портит сводку — в статистике сцены
появляется чужой ответ.

**Все шесть языков обязательны.** Схема отвергает пакет, где у понятия нет
написания на одном из языков (ТЗ строка 95).

**Башкирский требует проверки носителем.** Он написан по доступным источникам и
не выверен; сборка перечисляет такие слова отдельным списком, и до приёмки этот
список должен пройти через человека, знающего язык. Ошибка в учебном пособии
хуже пропуска: ребёнок запомнит неверное слово.
