# @kiosk/inophone-library

Пакет учебного контента виджета «Инофон» (Тип 4): темы, сцены, словарь на
шести языках, озвучка.

Формат описан и проверяется в `@kiosk/shared`, `src/inophone/model/schema.ts` —
второго описания здесь нет намеренно: пакет собирается скриптами, и единственное,
что отделяет опечатку в идентификаторе от занятия, где половина сцены не
откликается, — разбор при сборке и при старте приложения.

## Раскладка

```
index.json              темы, сцены, словарь
assets/img/scenes/<id>.svg      подложка сцены
assets/img/concepts/<id>.svg    иллюстрация понятия для словаря
assets/audio/<язык>/<id>.mp3    произношение
```

**Язык — каталогом, а не суффиксом в имени.** Добавление языка не трогает ни
одного существующего файла, а удаление языка сводится к удалению одного
каталога. У эталона язык вшит в имя файла (`0001bak.mp3`), и вычистить язык из
поставки там означает пройти по всем 2650 файлам.

## Состояние

Сейчас в пакете **затравочный** набор: одна тема, одна сцена, несколько
понятий. Он существует, чтобы цепочка «пакет → протокол → экран» проверялась
живым запуском, а не только сборкой. Объём по ТЗ (≥5 тем, ≥31 сцена, ≥350 слов
на шести языках) набирается в Фазе 4.

Что именно недостаёт, приложение говорит **поимённо**: экран «Сведения о
пакете» показывает отчёт `checkCompleteness` и `checkQuotas` с запасом по
каждой квоте.
