# packages/natcom-library

Библиотека (фоны/категории/объекты) виджета «Конструктор природных
сообществ» (Тип 5), вшиваемая в сборку `player` через `extraResources` —
тот же принцип, что `packages/chrono-templates` у Хронолинии: папка ДАННЫХ
без `package.json`/кода, читается `player`'ом на этапе своей сборки/рантайма
относительным путём, без symlink.

## ⚠️ Текущее содержимое — заглушка, НЕ реальный контент

`index.json` и `assets/*.svg` в этой папке — минимальный набор для
разработки UI (Тип5_бэклог.md, Эпик 4+, задача T5-101): 1 фон, 2 категории,
6 объектов. Изображения — простые сгенерированные SVG-плейсхолдеры (цветной
прямоугольник с подписью), не заимствованный контент, но и не то, что
должно попасть к реальному пользователю.

Реальный контент (7 фонов из ТЗ, полноценный каталог объектов с настоящими
изображениями/видео-анимациями/описаниями, 7 готовых презентаций) —
отдельная, нетехническая задача (Тип5_бэклог.md, Эпик 11) с собственным
источником/бюджетом, ещё не решена.

## Формат

`index.json` — документ, проходящий `parseNatComLibrary()`
(`@kiosk/shared`, `packages/shared/src/naturalCommunities/model/project.ts`):

```
schemaVersion: 1
backgrounds[]: { id, name, imageMediaId }
categories[]:  { id, name }
objects[]:     { id, categoryId, name, description, imageMediaId, animationMediaId? }
media[]:       { id, fileName, mimeType, fileSize, sha256 }
```

Медиафайлы (`media[]`) описывают файлы в `assets/` по имени (`fileName`);
`imageMediaId`/`animationMediaId` у фонов/объектов — ссылки на `media[].id`,
не на путь напрямую.
