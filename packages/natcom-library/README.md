# packages/natcom-library

Библиотека (фоны/категории/объекты) виджета «Конструктор природных
сообществ» (Тип 5), вшиваемая в сборку `player` через `extraResources` —
тот же принцип, что `packages/chrono-templates` у Хронолинии: папка ДАННЫХ
без `package.json`/кода, читается `player`'ом на этапе своей сборки/рантайма
относительным путём, без symlink.

## Текущее содержимое — пилот реального контента, сообщество «Лес» (1 из 7)

`index.json` и `assets/*.png` — первая партия РЕАЛЬНОГО контента (не
заглушка): T5-102, Эпик 11, пилот 2026-09-06. 1 фон + 14 объектов
(5 млекопитающих, 4 птицы, 4 растения, 1 земноводное) сообщества «Лес» —
изображения сгенерированы через syntx.ai (Nano Banana), не заимствованы у
вендора; тексты описаний написаны заново. Объекты — PNG с прозрачным фоном (белый фон генератора убран пороговой
заменой на альфа-канал, скрипт `Тип5_Конструктор_сетевая/скрипты/
remove_white_bg.py` в папке проекта, требует Pillow/numpy); фон-пейзаж —
непрозрачный PNG. Промпты и методика — `Тип5_контент_пилот_Лес.md`
в папке проекта (не в репозитории).

Остаётся сделать (Эпик 11, T5-102): ещё 6 сообществ (Арктика, Тундра, Тайга
сибирская, Тайга дальневосточная, Степь, Пустыня) и ~98 объектов по тому же
образцу; 7 готовых презентаций (по одной на сообщество); анимации/видео
поведения объектов (`animationMediaId` в схеме уже есть, синтез видео через
syntx.ai не проверялся отдельно от статичных изображений).

## Формат

`index.json` — документ, проходящий `parseNatComLibrary()`
(`@kiosk/shared`, `packages/shared/src/naturalCommunities/model/project.ts`):

```
schemaVersion: 1
backgrounds[]: { id, name, imageMediaId }
categories[]:  { id, name }
objects[]:     { id, categoryId, name, description, imageMediaId, animationMediaId? }
media[]:       { id, fileName, mimeType, fileSize, sha256 }
```

Медиафайлы (`media[]`) описывают файлы в `assets/` по имени (`fileName`);
`imageMediaId`/`animationMediaId` у фонов/объектов — ссылки на `media[].id`,
не на путь напрямую.
