# packages/natcom-library

Библиотека (фоны/категории/объекты) виджета «Конструктор природных
сообществ» (Тип 5), вшиваемая в сборку `player` через `extraResources` —
тот же принцип, что `packages/chrono-templates` у Хронолинии: папка ДАННЫХ
без `package.json`/кода, читается `player`'ом на этапе своей сборки/рантайма
относительным путём, без symlink.

## Текущее содержимое — реальный контент, все 7 природных сообществ

`index.json` и `assets/*.png` — РЕАЛЬНЫЙ контент (не заглушка): T5-102,
Эпик 11, завершено 2026-09-06. 7 фонов + 89 объектов (5 категорий:
Млекопитающие, Птицы, Растения, Земноводные, Пресмыкающиеся) по сообществам:

| Сообщество | Объектов |
|---|--:|
| Лес | 14 |
| Арктика | 11 |
| Тундра | 13 (+ Песец из «Арктики», переиспользован) |
| Тайга сибирская | 14 |
| Тайга дальневосточная | 19 |
| Степь | 9 |
| Пустыня | 9 |
| **Итого** | **89** |

Изображения сгенерированы через syntx.ai (Nano Banana), не заимствованы у
вендора; тексты описаний написаны заново. Виды в основном взяты из
биологически достоверного мастер-списка оригинала (112 видов,
`Конструктор_сетевая_1.0.0_СПЕЦИФИКАЦИЯ_воспроизведения.md`, раздел 8), с
несколькими осознанными дополнениями там, где в списке не хватало
подходящих видов для конкретного биома (например, Дрофа для степи, Джек и
Саксаульная сойка для пустыни) — все дополнения реальны и биологически
достоверны, не выдуманы. Объекты — PNG с прозрачным фоном (белый фон
генератора убран пороговой заменой на альфа-канал, скрипт
`Тип5_Конструктор_сетевая/скрипты/remove_white_bg.py` в папке проекта,
требует Pillow/numpy); фоны-пейзажи — непрозрачные PNG. Промпты и методика
пилота — `Тип5_контент_пилот_Лес.md` в папке проекта (не в репозитории),
тот же процесс повторён для остальных 6 сообществ.

Живой прогон: реальный embedded-сервер (`server.js`) отдаёт все 96
медиафайлов через `/library-assets/`, композит объектов поверх фонов в
реальном браузере — чисто, без белых ореолов, для нескольких сообществ.

## Видео поведения объектов (T5-104)

8 объектов имеют `animationMediaId` — видео поведения (5с, 960×960, h264+
aac, сгенерировано через syntx.ai, модель Kling 3.0 Turbo, режим Image to
Video, вход — уже готовое изображение объекта, стиль сохранён): Медведь
бурый, Неясыть (Лес — оба из первоначального пилота), Медведь белый
(Арктика), Олень северный (Тундра), Лось (Тайга сибирская), Тигр
уссурийский (Тайга дальневосточная), Сайгак (Степь), Верблюд двугорбый
(Пустыня) — по одному «флагманскому» животному на сообщество (кроме Леса,
где их два). Осознанный охват: ТЗ (FR-008) требует лишь наличия и рабочей
демонстрации «динамического видеоряда», не видео на каждый объект — у
остальных 81 объекта `animationMediaId` отсутствует, это предусмотрено
схемой (поле опционально). Живой прогон: реальный packaged Electron + CDP —
открытие готовой презентации «Лес», клик по медведю на сцене (реальные
Konva-координаты), карточка объекта показывает видео `readyState=4`,
`videoWidth/Height=960×960`, `currentTime` реально продвигается между двумя
проверками (не статичный кадр) — подтверждённое воспроизведение, не только
факт загрузки.

Остаётся (Эпик 11, за пределами T5-102/T5-103/T5-104): решение — расширять
ли видео-охват дальше 8 объектов (не требуется формально ТЗ, техника
воспроизводима при необходимости).

## Формат

`index.json` — документ, проходящий `parseNatComLibrary()`
(`@kiosk/shared`, `packages/shared/src/naturalCommunities/model/project.ts`):

```
schemaVersion: 1
backgrounds[]: { id, name, imageMediaId }
categories[]:  { id, name }
objects[]:     { id, categoryId, name, description, imageMediaId, animationMediaId? }
media[]:       { id, fileName, mimeType, fileSize, sha256 }
```

Медиафайлы (`media[]`) описывают файлы в `assets/` по имени (`fileName`);
`imageMediaId`/`animationMediaId` у фонов/объектов — ссылки на `media[].id`,
не на путь напрямую.
